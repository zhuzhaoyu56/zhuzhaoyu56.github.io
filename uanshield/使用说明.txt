隅安智盾 iPad 网页版 使用说明
================================

这个文件夹就是整个 iPad 版，放到一个 https 网址上，iPad 用 Safari 打开后"添加到主屏幕"，
桌面上会多一个"隅安智盾"图标，点开是全屏运行的，没有浏览器地址栏。第一次打开后会存到 iPad 本机，
之后断网也能打开，比赛现场没有网络也不影响演示。


一、先把文件夹放到网上（三选一）
--------------------------------
要求：网址必须是 https 开头，否则断网后打不开。上传时保持文件夹结构不变（icons、splash 两个子文件夹要一起传）。

1. GitHub Pages（免费，推荐）
   新建一个公开仓库 → 把本文件夹里的全部文件上传到仓库根目录 →
   仓库 Settings → Pages → Branch 选 main、目录选 / (root) → Save。
   等一两分钟，页面上会给出网址，形如 https://你的用户名.github.io/仓库名/

2. Netlify
   登录 https://app.netlify.com/drop ，把整个文件夹拖进网页，几秒后给出一个 https 网址。

3. 临时用电脑开（电脑和 iPad 连同一个 Wi-Fi）
   在本文件夹里运行：python -m http.server 8000
   iPad 的 Safari 打开 http://电脑的IP:8000
   这种方式也能添加到主屏幕、全屏运行，但不是 https，不能离线，演示时电脑要一直开着。


二、在 iPad 上安装
------------------
1. 用 Safari 打开上面的网址（必须是 Safari，其他浏览器不行）。
2. 点地址栏右边的"分享"按钮 → "添加到主屏幕" → 右上角"添加"。
3. 回到桌面，点"隅安智盾"图标打开一次，保持联网。
   底部出现"已保存到本机，断网也能打开"，就说明缓存好了。
4. 之后断网也能直接从桌面打开。


三、全屏
--------
- 从主屏幕图标打开，本身就是全屏，没有地址栏和标签栏。
- 如果只是在 Safari 里打开，右上角有一个全屏按钮（深浅色切换按钮左边），点一下进入全屏。
- 安全百科里的科普短视频，播放条最右边的按钮可以全屏播放，再点一次退出。


四、其他
--------
- iPad 版默认深色界面，右上角太阳/月亮按钮可以切换，选择会记住。
- 左侧栏底部"演示控制"里的"合法任务""越界攻击"，以及"更多场景"里的"高风险操作确认"等，
  可以在评委面前现场触发告警、弹窗和手机推送。
- 所有组织、人员、终端和告警都是虚构的演示数据，不连接任何真实设备。
- 以后如果替换了文件，iPad 上需要联网打开两次，第二次才会换成新版本。
- 竖屏、横屏都能用；横屏时左侧菜单完整展开，竖屏时自动收起成图标。
- 建议 iPadOS 16 或更新的系统。
